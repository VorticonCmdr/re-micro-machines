Click to skip the logo. On the code card any symbol is accepted: press ENTER twice. On GAME OPTIONS, F1/F2 pick each player's controls, F3 the sound, F4 the smoothness, F5 redefines the keys, F6 shows the credits, RETURN plays and ESC quits. KEYS 2: arrows steer, up accelerates, down brakes, S fires. KEYS 1: J L I M K. A gamepad appears as JOY 1 (and a second one as JOY 2) once you press one of its buttons: the stick or d-pad steers, A accelerates, B brakes, and either fires; F7 calibrates it. In a race, SPACE pauses and ESC quits to the title. The game files load from /game; if they aren't there, use "Open game folder…" or drop the folder on the page.
